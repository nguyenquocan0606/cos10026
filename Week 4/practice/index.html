Week 4: Luyện CSS từng bước

Cách làm mỗi bước:
  1. Mở trang của bước đó trên trình duyệt. Góc phải dưới có bảng chấm điểm.
  2. Đọc phần 📖 Lý thuyết nhanh trong bảng.
  3. Mở file style.css của bước đó trong VS Code, làm theo các dòng TODO.
  4. Lưu file (Ctrl+S), rồi bấm 🔄 Chấm lại (hoặc F5).
  5. ❌ thì đọc dòng "Trình duyệt đang thấy" và 💡 gợi ý để sửa. Đủ ✅ thì sang bước tiếp.
  6. Các mục 🧠 là thí nghiệm hoặc câu hỏi tự kiểm tra, tự tick khi làm xong.

Các bước

  1. Gắn CSS vào HTML + thứ tự ưu tiên (sửa cả index.html và style.css)
  2. Selectors: *, type, .class, #id, [attribute]
  3. Font, text-align, border
  4. Màu: tên, RGB, HEX, HSL, RGBA, gradient, hover
  5. Ảnh nền: size, position, repeat
  6. Box model: padding, border, margin
  7. Tổng hợp: thanh menu ngang
